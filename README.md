# 📝 React ToDo App with Context API & LocalStorage

A simple and lightweight ToDo application built using **React**, **Context API**, and **LocalStorage**. This project allows users to add, edit, delete, and mark tasks as completed — all data is saved in the browser without the need for a backend.

---

## 🚀 Features

- ✅ Add new todos
- ✏️ Edit existing todos
- ❌ Delete todos
- ✔️ Mark todos as completed
- 💾 Data persistence using localStorage
- 🧠 State management using Context API
- 💅 Styled with Tailwind CSS
